# 个人网站升级与验收记录

验收日期：2026-09-11。项目目录：`E:\APP\personSit`。

## 设计与内容

首页采用暖白 / 墨色双主题、蓝色强调与彩色肖像，组织为“认识本人 → 代表作品 → 能力证据 → 成长路径 → 方法笔记”。保留读者熟悉的项目、经历、关于、笔记和联系导航。

重点面向招聘者的阅读路径：

1. 由首页“30 秒了解我”进入简历速览。
2. 查看岗位、教育、奖项与校园责任的真实时间线。
3. 从能力进入对应项目，了解职责、实现、思考及公开边界。
4. 体验“馬哥小馆儿”本地点餐流程，或带着项目上下文生成咨询邮件。

五个案例来源于既有公开资料：馬哥小馆儿、采购平台与招标小程序、隧道病害图像识别与标注、东软培训中的外卖平台项目、机器人与少儿编程教学。不把培训项目表述为阿里巴巴任职经历，不虚构业务增长、模型准确率或获奖内容。

三篇方法笔记是本次根据公开经历整理的新增正文，不冒充过往 CSDN 原文。首页的“30 篇”明确指过往 CSDN 写作经历，与本站 3 篇笔记分开。

## 浏览器实测

使用应用内浏览器检查真实本地页面，未使用脚本直接改变页面状态来替代访客操作。

| 检查项 | 结果 |
| --- | --- |
| 彩色照片 | 浅色与深色模式均保留彩色，图像没有灰度滤镜 |
| 深浅色模式 | 点击切换成功，跨页面保持选择 |
| 全站搜索 | 简体“马哥小馆儿”匹配代表作与相关笔记，Enter 打开项目 |
| 搜索空态与快捷键 | 无匹配时显示可继续探索提示，Ctrl K 开关，Escape 关闭 |
| 首页能力方向 | 鼠标点击与方向键切换对应面板及证据链接 |
| 项目组合筛选 | 研究分类得到 1 项，与“微信”组合得到 0 项，重置恢复 5 项 |
| 点餐演示 | 添加、减少、0–9 份边界、确认记录、重置均正常 |
| 简历 / 文章锚点 | 点击后 hash 与内容对应，标题保留约 100–112px 顶部间距 |
| 关于页工作方式 | 原生 details / summary 点击正常展开 |
| 邮件草稿 | 空称呼被阻止；项目上下文预填正确；中文与 & 正确编码；编辑后隐藏旧草稿 |

| 手机导航 | 展开后聚焦导航，选择页面后收起 |
| 响应式 | 390px 与 320px 下首页、作品、案例、简历、关于、笔记、联系与成长足迹无横向溢出 |

| 404 | 中文说明与有效返回入口，标记 noindex |

## 可靠性与边界

- 图片由 Astro 转成响应式 WebP；首页肖像优先加载，作品图片按需加载。
- 动效尊重 prefers-reduced-motion。手机菜单、主题与复制按钮由脚本就绪状态控制；主要内容和锚点不用依赖脚本。
- 禁用脚本时，首页能力内容全部可读；项目筛选 / 点餐控件禁用并解释；联系表单禁用，保留直接邮箱链接，避免默认 GET 泄露草稿内容。
- 点餐模块是本站示例，不连接生产小程序、不产生真实订单、不保存个人信息。
- 邮件表单只生成草稿。验收没有对外发送邮件，也没有操作任何真实订单。
- A4 打印样式已实现并静态检查；系统打印对话框与具体打印机分页不在本次自动化验收范围内，发布前可人工查看一次 PDF 预览。
- 没有添加访客追踪、后端留言服务、虚假实时指标或需要密钥但无法工作的 AI 对话框。
- 本次只完成本地修改与验证，没有提交、推送或部署。真实小程序码、生产截图或更多可公开材料，需由本人确认后补充。
