# 滚动分镜 v2

基于已合并的 PR #1（1e228e6）延续实现。原接续提示词中“未合并”的状态已过时。本轮不合并、不正式部署。

| 场景 | 起点 → 终点 | 滚动区间 | 景深和阅读 | 移动端 |
| --- | --- | --- | --- | --- |
| 首屏 | 原位轻缓落位 → 标题先离场、头像后离场 | 首屏顶部到首屏底部，约740px | 标题 -90px、完整头像 +65px / 1.5度；无透明度隐藏 | 无首屏视差 |
| 交接 | 作品画幅 94% → 100% | 顶部从视口90%到22% | 内容连续接续，沿用版面间距 | 无画幅缩放 |
| 作品 | 图片1.16 → 1；标题/说明/按钮分别位移44/32/20px至原位 | 图片从入场到轨道底部抵达窗口底部；文案在舞台抵达100px时完成 | 短暂停驻320px，全部文案完成进入后保留稳定阅读 | 无停驻，图片仅1.025→1 |
| 卡片 | 当前卡1 → .95、下一卡进入 | 下一卡锚点从75%视口到170px | 18px叠层；章节自然流锚点同步 | 自然流列表 |

- 完整桌面镜头仅在宽≥1000、高≥720且精确鼠标输入下启用。
- 统一scrub .25秒，进度条直接跟随；保留原生滚动，不引入平滑滚动库。
- 头像最大406px，不分层重画、不增加重复签名、不宣称高分辨率。
- 键盘进入任一项目卡时整个卡组恢复自然流；减少动态同样恢复文档流。
- 没有opacity:0入场。未加载JS也可以直接阅读。
- 不加鼠标磁吸：当前按钮已有方向反馈，避免与滚动形成多套阻尼。
- huangbai-scrolling参考：采用连续镜头安排。该仓库通过预渲染视频实现滚动推进，当前只有静态素材；不适合直接接入其整段视频加载方案，故不引入视频与额外内存负担。
- 阅读时间由用户控制；上表是滚动距离，不保证固定秒数或帧率。
