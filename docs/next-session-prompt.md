## 请先交付滚动分镜，再实现

用一张简洁表格说明各段的起始状态、结束状态、滚动距离、前后景变化、文本可读时间、桌面与手机差异。给出具体可调参数。不要先堆一批特效再寻找用途。

1. 首屏：标题、头像构图、背景纸面形成前后层次。进入时有轻缓的落位；滚动时可清晰感知相对速度。任何倾斜、缩放都不能挤压或裁掉脸部和签名。
2. 首屏到作品区：有明确的视觉交接，例如构图收束后作品画面展开；避免仅用一个大空白把两段分开。保持自然、可预期的滚动。
3. 代表作品：考虑场景由近到远或由整体到细节的推进。内容要留出阅读时间；标题、说明和按钮按镜头节奏进入。停驻必须服务叙事，不能制造长时间滚不出去的感觉。
4. 项目卡片：采用短而明确的接力关系；缩放、层级、位置和当前章节同步。读者可以随时点击项目；键盘焦点不能被前景卡片挡住。
5. 鼠标反馈：可选小幅倾斜或磁吸，用于可点击目标；触屏禁用，避免所有元素都晃动。

滚动手感需要实际体验。先评估现有原生滚动 + scrub 的问题，只有在能说明收益、验证键盘与触屏兼容时才引入平滑滚动库。不要拦截触摸手势、嵌套滚动或锚点导航。避免多套阻尼叠加造成跟手延迟。

## 手机、平板与无障碍

- 桌面可使用完整分镜、短距离停驻与叠放。
- 手机采用短节奏、轻量动画和顺畅纵向阅读，不能机械缩小桌面长镜头。
- 平板根据实际宽度、高度和输入方式调整，横屏矮窗口也必须可用。
- 尊重 prefers-reduced-motion，保留手动关闭动效并记住偏好；关闭后恢复正常文档流。
- 无 JS 时内容可读、主链接可用；不以初始 opacity:0 隐藏所有内容。
- 保留浅色/深色主题、菜单、站内搜索、能力标签、项目详情、经历、笔记和联系方式。
- 不编造履历、项目数据和成绩。
