# 标签、图标与移动流量优化

日期：2026-09-11。用户确认访问慢的是 GitHub Pages 地址，目前没有自有域名。

## 本轮改动

- 16 个页面的浏览器标签统一为「马志昊的个人网站」，分享元信息保留各页面的具体主题。
- favicon 改为蓝底白字 MZH，独立文件 `favicon-mzh.svg` 避免沿用旧图标缓存。
- 字体改为系统字体，移除页面中的 FontSource 和全套 Font Awesome 字体 / CSS 导入。
- 8 个实际使用的图标通过 `Icon.astro` 在构建时内嵌原有 SVG，保留许可证说明，不加载图标字体。
- 保留上一轮的响应式 WebP、首屏头像优先加载、项目图懒加载。

## 实测与资源核验

- 测试：12 项通过；Astro 检查 34 个文件，0 错误 / 警告 / 提示。
- 默认及 GitHub Pages 构建通过：16 个页面、75 个锚点，链接审计 0 失败。
- 浏览器检查了桌面和 390px 手机首页、标签、SVG 图标与最终日志，无横向溢出或运行错误。
- 所有产物页面无自动加载的第三方资源；产物内字体文件、字体引用及 @font-face 均为 0。

CSS 的 gzip 体积减少约 75.7%。SVG 内嵌略微增加 HTML，但 HTML 与 CSS 合计仍净减少 26375 字节，且不再等待字体请求。压缩数值来自本地构建，不代表中国运营商线路实测时间。

只读检查确认，GitHub Pages 仍为 2026-08-10 旧版本，引用三张 PNG：头像 1598831 字节、项目图 2086571 字节、页脚头像 1520652 字节，整页图片共 5206054 字节。后两张是懒加载，不应把整页图片总量当作首屏流量。

本地新版首页只有两张 WebP，最大合计 75206 字节，整页图片比线上旧版减少约 98.6%。本轮没有发布，因此这些优化尚未在公开 GitHub 地址生效。

## 国内访问边界

资源减小能缩短下载阶段，但不能保证跨境链路的连接速度。缺少国内移动网络探针，本次没有对中国移动 / 联通 / 电信作实际测速，也不保证 GitHub Pages 的国内可用性。

可先发布轻量版，再用用户的真实手机网络复测。如果之后需要大陆节点加速，须先准备自有域名并确认备案与服务方案。EdgeOne 官方说明：接入大陆 / 含大陆区域的自定义域名需要备案；默认项目域名在大陆网络下有临时预览链接限制，不适合作为长期分享地址。
